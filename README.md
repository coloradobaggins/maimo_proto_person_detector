## Person detector app

App Prototipo para tesis de la Universidad Maimonides.
La app simula una terminal de un museo, que adapta su contenido en funcion de la persona que detecta (adulto, niño, ambos, ninguno).

Para correr el proyecto:

```bash
npm run dev

```

La app se ejecuta en [http://localhost:3000](http://localhost:3000)
